Airgap

A local-first data governance & PII lineage auditor for DataHub. An air-gapped auditor for the data you can't afford to leak.

The problem

PII is classified at the source.
Then lineage forgets.

  • A column tagged PII flows through staging, marts, marketing tables and ML features — but the classification doesn't travel with it.
  • Downstream copies land untagged, often in assets with no owner — nobody is accountable.
  • Auditing it means walking the lineage graph by hand. It doesn't scale.
  • Automate it with a cloud LLM and you leak the very metadata you're protecting.
The insight

The tool that protects your data shouldn't leak it.

Detection is deterministic local code. Explanations come from a local model. The only network call is a read to the DataHub you point at.

DataHub integration

DataHub is the context platform

Read (GraphQL)

Paginate datasets, then pull field-level tags & glossary terms, ownership, and dataset- + column-level lineage (fineGrainedLineages).

Normalize

Map responses into Asset / Field / LineageEdge; split schemaField URNs so columns line up with lineage.

Write back

Emit acryl-datahub SDK code to re-tag fields or assign owners — reviewed, then merged.

Read-only against your instance. The fixture mirrors DataHub's exact URN & schema model.

Detection

Two rules, real evidence

R1 — Untagged PII propagation

A classified field flows into a downstream field/dataset carrying no equivalent classification.

R2 — Ownerless sensitive asset

A dataset holding PII (directly or by lineage) has no owner. Nobody is accountable.

users.email → stg_users.email → dim_customer.email → marketing_enriched.email ⚠ untagged

Severity = blast radius. PII reaching a human-facing dashboard escalates to CRITICAL.

Why it matters
